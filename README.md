## 🚀 Tech Stack

### **Frontend**
- React + Vite  
- TailwindCSS  
- Zustand global store  
- React Query for caching  
- AI chat widget  
- Premium gating + Stripe client flow  

### **Backend**
- FastAPI REST API  
- SQLAlchemy ORM  
- Alembic migrations  
- JWT authentication  
- Stripe subscription flow  
- Dockerized deployment  

### **Deployment**
- Vercel (Frontend)  
- Render (Backend)  
- Netlify alternative
